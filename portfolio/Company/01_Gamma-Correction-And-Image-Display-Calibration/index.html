Gamma Correction & Image Display Calibration

01. 專案背景

AOI 系統取得 Camera Image 後，需要將影像顯示於 Software Application 中，供 Operator 進行影像檢視與判斷。

然而，從實際物體經過 Camera Capture、Image Processing 到 Software Display 的過程中，影像的亮度與灰階分布可能與實際物體的視覺效果產生差異，進而影響影像判讀。

因此，本專案導入 Gamma Correction，透過調整影像的 Tone / Intensity Distribution，改善 Software Display 與實際物體之間的視覺差異。

本專案的主要工程問題為：

如何在既有 AOI Image Display Pipeline 中加入可調整的 Gamma Correction，使影像顯示結果更符合實際檢視需求？

我主要負責 Gamma Correction Function、Gamma Parameter UI，以及與既有 Image Display Pipeline 的整合。

02. 專案目標與系統架構

2.1 專案目標

本專案的主要目標，是建立可調整的 Image Display Calibration Capability。

主要包含：

  • 建立 Gamma Correction Function
  • 建立 Gamma Parameter Adjustment Panel
  • 將 Gamma Correction 整合至既有 Image Display Pipeline
  • 透過 Gamma Parameter 調整影像亮度與 Tone Distribution
  • 提供 Operator 可調整的 Image Display Calibration 能力
  • 改善 Software Display 與實際物體之間的視覺差異

核心概念為：

Camera Image → Image Processing → Gamma Correction → Software Display

2.2 System Architecture

Gamma Correction 位於既有 Image Processing 與 Software Display 之間。

Camera Image 經過既有處理流程後，進入 Gamma Correction，依據設定的 Gamma Parameter 進行影像轉換，再將調整後的影像提供給 Software Display。

同時，Gamma Parameter 由 UI 提供調整介面，使 Operator 可以根據實際影像效果進行 Calibration。

因此，Gamma Correction 不需要改變原有 Camera Acquisition Flow，而是作為既有 Display Pipeline 中的一個可調整影像處理功能。

03. 我的設計與實作

3.1 Gamma Correction Function

我負責設計與實作 Gamma Correction Function，將 Gamma Parameter 應用於 Camera Image。

Gamma Correction 透過影像強度轉換調整影像的 Tone Distribution，使不同亮度區域呈現適合檢視的影像效果。

在設計上，將 Gamma Parameter 與 Image Transformation 分離，使 Gamma Correction 可以透過外部參數進行調整，而不需要修改底層 Image Processing Logic。

3.2 Gamma Parameter UI

除了底層 Image Processing Function，我也負責建立 Gamma Parameter Panel，讓 Operator 可以直接調整 Gamma Parameter。

Parameter 調整後，影像會套用新的 Gamma Correction，再更新 Software Display。

因此，Gamma Correction 從固定的 Software Parameter 轉換成可由使用者操作的 Calibration Function。

3.3 Image Display Pipeline Integration

我將 Gamma Correction 整合至既有 AOI Image Display Pipeline，而不是建立獨立的 Image Processing Flow。

整合後，原有的 Camera Image Acquisition 與 Image Processing Workflow 可以維持，Gamma Correction 則在影像進入 Display 前進行處理。

這種設計可以降低對既有 AOI Application 的影響，同時讓 Image Display 擁有額外的 Calibration Capability。

3.4 Image Display Calibration

Gamma Parameter 的設定不只是單純讓影像變亮或變暗，而需要觀察不同 Parameter 對影像 Tone Distribution 與實際視覺效果的影響。

因此，我透過實際影像進行 Parameter Tuning，比較 Camera Captured Image、Gamma-adjusted Image 與 Software Display Result，確認不同 Gamma Parameter 對影像呈現的影響。

再根據實際檢視需求調整 Parameter，使 Software Display 達到適合 Operator 判讀的影像效果。

3.5 Engineering Problem Handling

本專案的主要工程問題是 Image Representation Difference。

Camera 所取得的影像經過 Image Processing 與 Software Display 後，不一定能直接呈現符合實際檢視需求的視覺效果。

因此，我將問題拆分為：

Image Acquisition → Image Transformation → Display Evaluation

再透過 Gamma Parameter 將 Image Transformation 做成可調整的功能。

如此可以透過：

Parameter Adjustment → Image Display → Visual Evaluation

反覆進行 Calibration，而不需要修改原有 Camera Acquisition 或 Inspection Logic。

04. 成果

完成 AOI Software 的 Gamma Correction Capability，使 Camera Image 可以透過 Gamma Parameter 進行影像 Tone 與亮度調整。

建立 Gamma Parameter Panel，讓 Operator 可以直接進行 Image Display Calibration，並根據實際影像效果調整相關參數。

同時完成：

Camera Image → Image Processing → Gamma Correction → Software Display

的整合，使 Gamma Correction 成為既有 AOI Image Display Pipeline 的一部分。

透過實際影像比較與 Parameter Tuning，改善 Software Display 與實際物體之間的視覺差異，提供較一致的影像檢視方式。

本專案將 Image Processing、Parameter Control、UI Development 與 AOI Application Integration 結合，建立可調整的 Image Display Calibration Capability。

核心成果可以歸納為：

Fixed Image Display → Parameterized Image Display

Manual Visual Adjustment → Software-based Calibration

Standalone Image Processing → Integrated AOI Display Pipeline
