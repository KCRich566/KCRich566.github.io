Wafer Die Defect Inspection

An AI-based wafer inspection workflow that uses CNN image classification to detect die appearance defects and deploys the model into production inspection.

01. 專案背景

Wafer 生產過程中，需要檢測每個 Die 的外觀是否存在瑕疵。

傳統檢測方式受到人工判斷與抽樣檢查方式限制，難以對所有 Die 維持一致的檢測標準。當瑕疵未被及時發現，也可能進一步造成品質異常與客戶端問題。

因此，本專案導入 AI-based Image Inspection，透過高倍率相機取得 Die Image，再使用 CNN Image Classification Model 自動判斷 Die 是否存在外觀瑕疵。

本專案的主要工程問題為：

如何將 Wafer Die 的影像資料轉換成可部署於 Production Environment 的 AI Inspection Workflow，讓系統能夠對生產中的 Die 執行自動化瑕疵分類？

我主要負責 Vision Inspection、AI Model Development，以及模型與 Production Inspection Workflow 的整合與部署。

02. 專案目標與系統架構

2.1 專案目標

本專案的主要目標，是建立 Wafer Die 自動化外觀瑕疵檢測能力。

系統需要完成：

  • 透過高倍率相機取得 Die Image
  • 建立 Good / Bad Image Dataset
  • 建立 CNN Image Classification Pipeline
  • 使用 ResNet-50 建立 Defect Classification Model
  • 建立 Model Training 與 Evaluation Flow
  • 使用 Transfer Learning 進行模型迭代
  • 將模型整合至 Production Inspection Workflow
  • 對生產中的 Die 執行自動化全檢

核心概念為：

Image Acquisition → Image Processing → AI Classification → Inspection Decision

同時建立 AI Development 與 Production Inspection 之間的 Feedback Loop，使新的 Production Data 可以持續回饋至後續模型開發。

2.2 System Architecture

整體系統可以分為 AI Development Pipeline 與 Production Inspection Pipeline。

AI Development Pipeline

Good / Bad Image Dataset 經過 Data Preparation 後進行 Model Training 與 Evaluation，再根據模型結果進行後續 Model Iteration。

Production Inspection Pipeline

Production Die 經過 Image Acquisition 與 Image Processing 後，送入 CNN Model 進行 Classification，最後產生 Good / Bad Inspection Result。

完成 Production Inspection 後，實際產生的影像資料與結果也可以作為後續 Dataset Update 與 Model Retraining 的來源。

因此，整體架構形成：

Dataset → Training → Evaluation → Production Inspection → New Data → Model Iteration

03. 我的設計與實作

3.1 Image Acquisition & Inspection Pipeline

我負責將高倍率影像取得整合至 Die Inspection Workflow。

每個 Die 的影像作為 AI Model 的 Input，提供後續影像分類所需的資料。

由於檢測目標為 Die 上的外觀瑕疵，因此 Image Quality 與影像中 Defect Pattern 的可辨識程度會直接影響後續 Model Classification。

因此，我將 Image Acquisition、Image Processing 與 AI Classification 串接至同一套 Inspection Pipeline，使影像從取得到產生 Inspection Result 的流程保持一致。

3.2 CNN Image Classification

我使用 Python 建立 Image Classification Pipeline，將 Die Image 經過資料處理後送入 CNN Model。

模型主要學習 Good 與 Bad Die 之間的影像特徵，並將輸入的 Die Image 分類為：

  • Good
  • Bad

Model Classification Result 再回到 Inspection Workflow，作為後續 Inspection Decision 的依據。

因此，AI Model 並不是獨立存在的離線工具，而是整合於完整的 Image Inspection Pipeline 中。

3.3 ResNet-50 Model Development

專案初期，我使用收集到的 Good / Bad Die Image Dataset 建立 ResNet-50 Model Training Pipeline。

初期採用 From-Scratch Training 建立模型，先完成資料處理、Model Training 與 Evaluation Flow。

在後續模型開發過程中，為了提高模型迭代效率，改採 Transfer Learning。

當新的 Production Inspection Data 累積後，持續進行 Dataset Update、Model Retraining 與 Evaluation，完成驗證後再將更新後的 Model Deployment 至 Production Environment。

透過這種方式，模型開發不再是一次性的 Training Process，而是可以根據實際資料持續迭代。

3.4 Dataset & Model Iteration

AI Inspection 的模型開發不只包含 Model Training，也需要持續維護 Training Dataset。

我負責處理 Good / Bad Image Dataset，並根據新的 Inspection Data 持續更新資料。

模型開發流程因此形成：

Data → Training → Evaluation → Production → New Data → Retraining

透過持續累積實際 Inspection Data，使 Dataset 與 Model 可以隨著 Production Data 進行迭代。

3.5 Production Integration

完成 Model Training 與 Evaluation 後，我負責將模型整合至 Production Inspection Workflow。

Production Inspection 時，每個 Die 依序經過：

Image Acquisition → Image Processing → AI Classification → Good / Bad Decision

Model Result 再回到 Production Inspection Flow，作為 Die 是否通過檢測的依據。

因此，AI Model 不只是停留在 Offline Evaluation，而是實際整合至 Production Environment 執行 Inspection。

3.6 Production Feedback Loop

Production Environment 中持續產生新的 Inspection Data，因此模型需要能夠根據實際資料進行後續調整。

我將 Production Inspection 與 AI Development 串接，使新的資料可以回到 Dataset Preparation，進一步進行 Model Retraining 與 Evaluation。

完成評估後，再將符合需求的 Model 更新至 Production Inspection Workflow。

透過這個 Feedback Loop，建立：

Production Data → Dataset Update → Model Retraining → Evaluation → Production Deployment

使 AI Inspection 能夠持續根據實際資料進行模型迭代。

04. 成果

本專案建立以 Computer Vision 與 CNN Image Classification 為核心的 Wafer Die Automated Inspection Solution。

系統可以透過高倍率影像取得 Die Image，並使用 CNN Model 將影像分類為 Good / Bad，作為 Production Inspection Decision 的依據。

模型導入 Production Environment 後，對生產中的 Die 執行自動化全檢，將原本受到人工與抽樣方式限制的檢測流程轉換為自動化影像檢測。

同時建立完整的 AI Development Flow，從 Dataset Preparation、Model Training、Evaluation、Production Deployment 到 Model Retraining，使 Production Data 能夠持續回饋至模型開發。

最終將 Computer Vision、Deep Learning 與 Production Inspection Workflow 整合，建立可部署於實際生產環境的 AI-based Inspection Capability。

本專案的核心成果可以歸納為：

Manual / Sampling Inspection → Automated Image Inspection

Image Classification → Production Inspection Decision

One-time Model Development → Continuous Model Improvement
