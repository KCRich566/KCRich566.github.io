01. 專案背景

晶圓生產過程中，需要檢測 Wafer 上的 Notch 特徵，確認其尺寸與結構是否符合生產標準。

由於量產過程中可能產生不同程度的 Notch 形狀變化，單純依靠人工觀察容易受到人員判斷差異影響，因此需要建立一套基於影像分析的客觀檢測方法。

本專案透過高倍率影像取得 Notch 特徵，並利用已知 Good / NG 結果的影像資料進行分析，從影像中找出可以量化 Notch 品質的幾何特徵。

本專案的主要工程問題為：

如何從 Good / NG 影像中找出具有判別能力的 Notch Image Features，並將分析結果轉換成可以應用於量產的 Inspection Parameters？

我主要負責 Notch Inspection Application、Image Analysis、Feature Extraction，以及 Inspection Parameter / Threshold 的建立與 Production Integration。

02. 專案目標與系統架構

2.1 專案目標

本專案的主要目標，是建立 Notch 自動化影像檢測能力，將 Notch 的視覺特徵轉換成可以量化與判定的 Inspection Criteria。

主要包含：

  • 取得高倍率 Notch Image
  • 從影像中擷取 Notch 幾何特徵
  • 建立 Good / NG Image Dataset
  • 分析不同 Image Features 與品質結果之間的關係
  • 建立 Inspection Parameters 與 Threshold
  • 驗證判定條件
  • 將最終檢測條件導入 Production Inspection Workflow

核心概念為：

Image Acquisition → Feature Extraction → Feature Analysis → Parameter Development → Production Inspection

2.2 System Architecture

整體系統分為 Analysis Stage 與 Production Stage。

Analysis Stage 以已知 Good / NG 結果的影像資料為基礎，透過 Image Processing 與 Feature Extraction 取得 Notch 的幾何資訊，再分析不同 Feature 與品質結果之間的關係，建立適合的 Inspection Parameters 與 Threshold。

Production Stage 則使用已確認的 Inspection Parameters，對實際生產影像進行 Feature Extraction 與 Parameter Evaluation，最後產生 OK / NG Inspection Result。

透過這樣的架構，將前期的 Image Analysis 與 Parameter Development 結果轉換為可以實際部署的 Production Inspection Workflow。

03. 我的設計與實作

3.1 Notch Image Analysis

我使用 LabVIEW 開發 Notch Inspection Application，建立從影像取得、Image Processing 到 Inspection Result 的完整 Workflow。

首先從高倍率影像中取得 Notch 特徵，再透過 Image Processing 將 Notch 的相關線段與幾何特徵擷取出來。

由於 Notch 的影像結構可以透過線段與幾何關係進行描述，因此將影像轉換成可量化的幾何資訊，作為後續品質分析與判定的基礎。

3.2 Feature Extraction

我針對 Notch Image 建立幾何特徵分析，主要包含：

  • Notch Length
  • Notch Width
  • Line Segment Count

這些 Feature 將原本較難以客觀描述的 Notch 外觀，轉換成可以比較與分析的數值。

透過 Feature Extraction，後續可以進一步分析不同影像特徵與實際品質結果之間的關係。

3.3 Good / NG Dataset Analysis

為了建立適合 Production 使用的判定條件，我使用已知品質結果的 Good / NG Image Dataset 進行分析。

透過比較不同 Feature 在 Good 與 NG 樣本中的分布與差異，評估各項 Feature 是否具有足夠的判別能力。

分析的主要 Feature 包含 Length、Width 與 Line Segment Count。

不同 Feature 可能反映 Notch 不同的幾何特性，因此我透過多個 Feature 進行比較，而不是單純依賴單一影像特徵作為判定依據。

3.4 Parameter & Threshold Development

完成 Feature Analysis 後，我進一步將分析結果轉換成 Production Inspection Parameters。

不同 Feature 具有不同的判別能力，因此需要根據資料分析結果評估適合的 Parameters，並建立對應的 Threshold 與判定條件。

整個過程將：

Good / NG Samples → Feature Analysis → Parameter Evaluation → Threshold Selection

串接起來。

這使 Inspection Criteria 並非單純依賴人工經驗設定，而是建立在實際影像資料的分析結果上。

3.5 Production Integration

完成 Inspection Parameters 後，我將最終判定條件整合至 Production Inspection Workflow。

量產時，系統對取得的 Notch Image 執行：

Image Processing → Feature Extraction → Parameter Evaluation → OK / NG

讓前期 Analysis Stage 建立的檢測條件可以直接應用於 Production Stage。

因此，影像分析、Feature Extraction 與 Parameter Development 最終都被整合至實際的自動化 Inspection Flow 中。

3.6 Engineering Problem Handling

本專案的主要工程問題並不是單純取得影像，而是：

如何將影像中的視覺特徵轉換成可靠、可量化、可執行的 Production Inspection Criteria。

因此，我將問題拆分為三個階段：

Image → Feature → Inspection Criteria

首先透過 Image Processing 從影像中取得 Notch 特徵。

接著透過 Feature Analysis，確認 Length、Width、Line Segment Count 等特徵與 Good / NG 結果之間的關係。

最後再將分析結果轉換成 Production Parameters 與 Threshold。

最終形成：

Image → Feature → Parameter → Production Decision

04. 成果

本專案建立以 Image Processing 與 Feature Engineering 為核心的 Notch 自動化檢測系統，將 Notch 外觀特徵轉換成可量化的 Inspection Parameters。

透過 Notch Length、Notch Width 與 Line Segment Count 等幾何特徵，將原本較依賴人工觀察的 Notch 品質判斷，轉換為基於影像特徵的量化檢測流程。

同時，透過 Good / NG Image Dataset 進行 Feature Analysis，建立與實際品質結果相對應的 Inspection Parameters 與 Threshold。

最終完成：

Image Acquisition → Image Processing → Feature Extraction → Parameter Evaluation → OK / NG

的 Production Inspection Workflow，使前期建立的檢測條件能夠應用於實際生產環境。

本專案將 Computer Vision、Feature Engineering、Parameter Development 與 Production Integration 串接起來，建立可重複執行的 Notch Quality Inspection Capability，提升檢測結果的一致性。
